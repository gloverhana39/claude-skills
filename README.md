# claude-skills

Claude 用のスキルをまとめて管理するリポジトリです。
プログラミングのプロジェクト（`~/projects` 配下の各リポジトリ）とは分けて管理しています。

- 置き場所（Mac）：`~/claude-skills`
- 公開範囲：Private

## スキル一覧

| スキル | 呼び出し | 用途 | 状態 | 最終更新 |
|---|---|---|---|---|
| [nomura-summary](nomura-summary/) | `/nomura-summary <資料>` | 野村證券の投資・為替・金融経済資料（PDF）を要約し、テンプレートを使った編集できるPowerPointにまとめる | 運用中 | 2026-10-29 |

## 管理ルール

### フォルダ構成（どのスキルも同じ形にする）

```
<スキル名>/
├─ SKILL.md        … スキル本体（Claude に保存する内容と同じもの）
├─ README.md       … 取扱説明書（人が読むもの）
├─ CHANGELOG.md    … このスキルだけの変更履歴
├─ scripts/        … スキルが使うプログラム
├─ assets/         … テンプレートなどの素材
└─ examples/       … 手本・作成例
```

- 1スキル＝1フォルダ。フォルダ名はスキル名（小文字・ハイフン区切り）と同じにします。
- スキル同士でファイルを混ぜません。共通の部品が必要になったら、相談のうえ `_shared/` を作ります。

### 記録（コミット）のルール

- メッセージの先頭にスキル名を付けます。例：`[nomura-summary] 週報の手本を追加`
- リポジトリ全体の変更は `[repo]` を付けます。例：`[repo] README のスキル一覧を更新`
- 変更したら、そのスキルの `CHANGELOG.md` と、上のスキル一覧の「最終更新」も更新します。

### 版の目印（タグ）

- 区切りのよい版には、スキル名付きのタグを付けます。例：`nomura-summary/v1.0.0`
- 戻したいときは、そのタグの状態からファイルを取り出せます。

### 登録しないもの

- 原資料（PDF など）、スキルで作った成果物（要約デッキなど）、原資料から切り出した画像
  → 著作物・個人の資料のため。`.gitignore` で除外しています。

## Claude に保存されたスキルとの関係

- Claude が実際に使うのは、Claude の設定に保存されたスキル（SKILL.md の内容）です。このリポジトリと自動では連動しません。
- SKILL.md を変更したときは、Claude の画面で表示されるスキル更新の案を保存して、内容をそろえます。
- `scripts/` `assets/` `examples/` は、スキルが Mac の `~/claude-skills/<スキル名>/` から直接読み込みます。Mac で `git pull` すれば最新になります。

## Mac での基本操作

```
cd ~/claude-skills
git pull          # 最新を取り込む
git log --oneline # 変更の履歴を見る
```
