# /nomura-summary 取扱説明書

野村證券の投資・為替・金融経済資料（PDF）を要約し、指定テンプレートを使った**編集できるPowerPoint**にまとめるスキルです。

- 作成日：2026年10月29日
- 対象テンプレート：`FreeForm_Form16-10(メイリオ).pptx`（16:10・白地・メイリオ。EIZOロゴは削除済み）

---

## 1. できること

| 項目 | 内容 |
|---|---|
| 入力 | Mac の `011_公表情報` フォルダにある野村證券のPDF（1号ずつ） |
| 出力 | 要約デッキ（.pptx）。週次は8〜11枚程度、月次は12〜16枚程度 |
| 前号比較 | 同じシリーズの直前の号を自動で読み、投資判断・予想値・相場水準の変化をスライドに反映 |
| 図表・写真 | 原資料の表紙写真や図表を切り出して配置（出典ページ付き） |
| 自作の図解 | 結論カード、投資判断マトリクス、因果フロー、シナリオ表、カレンダー、比較表、ネイティブのグラフ |
| 保存 | Mac の資料フォルダ内の `可視化(Claude)/` に自動保存し、チャットにもファイルを添付 |

---

## 2. 使い方

### 基本形

```
/nomura-summary <対象の資料>
```

**起動するのは「/nomura-summary」と入力したときだけ**です。「野村の資料を要約して」とだけ頼んだ場合は起動せず、通常の会話で要約します。

### 指示の例

| やりたいこと | 入力例 |
|---|---|
| ファイル名で指定 | `/nomura-summary 野村週報(2026年10月26日_第4028号).pdf` |
| シリーズの最新号 | `/nomura-summary CIO Monthly の最新号` |
| 号を指定 | `/nomura-summary マンスリー投資会議 2026年10月` |
| 枚数を指定 | `/nomura-summary 野村週報 最新号を6枚で` |
| 重点を指定 | `/nomura-summary CIO Monthly 10月号、債券中心に` |
| 補足を許可 | `/nomura-summary 為替・金利展望の最新号、最新の為替水準も補足で` |

号を指定しなかった場合は、そのシリーズの最新号を対象にし、何を対象にしたかを最初に伝えます。

### 使う前に必要なこと

1. **Claude デスクトップアプリが起動していて、このMacとチャットが連携していること**
2. **資料フォルダが接続されていること**
   `/Users/hideo/disk01/02_Assets(資産)/01_資産運用/01_野村證券_全般/011_公表情報`
3. **スキル資材のフォルダが接続されていること**
   `/Users/hideo/claude-skills`（GitHub `claude-skills` の Mac 上のコピー）

   2・3が未接続の場合はClaudeがアクセス許可を求めるので、Mac側で承認してください。うまくいかないときは、メッセージ入力欄の「＋」→「フォルダを追加」から追加します。
4. スキルが Claude の設定に保存されていること（スキル一覧に `nomura-summary` があること）

## 3. 処理の流れ

```
① 対象PDFと前号PDF、スキル資材を取り込む
② 本文を抽出し、図で示された判断（CIO VIEW など）はページ画像で確認
③ 写真・図表を切り出し、目視で切れ・ずれを修正
④ 事実・数値・出典ページを一覧化 → 構成を決める
⑤ テンプレートに図表・図解・グラフを配置してデッキを作成
⑥ 検証（ファイル整合性・表示崩れ・数値の突き合わせ）
⑦ Mac の「可視化(Claude)」フォルダに保存し、チャットにも添付
```

所要時間の目安は1号あたり数分〜十数分です（ページ数と図表の数による）。

## 4. デッキの標準構成

| 順 | スライド | 中身 |
|---|---|---|
| 1 | 表紙 | 原資料の表紙写真を右側に大きく配置。資料名・号・発行日・比較対象・要約作成日 |
| 2 | 今週／今月の結論 | 要点3つをカードで。前号からの変化（判断変更・相場水準） |
| 3 | 判断・予想の一覧 | 例：CIO VIEW の5段階マトリクス（前月位置を点線丸＋矢印で表示） |
| 4〜 | テーマ別（1枚1メッセージ） | 左：原資料の図表、右：要点、下：「判断」または「ひとこと」の帯 |
| 後半 | 参考・予定 | 主要資産の推移、イベントカレンダー、制度解説など |
| 終盤 | 今後の注目点 | 「〜なら引き下げを検討」など、判断変更の条件をトリガー表に |
| 最後 | 用語ミニ解説と出典 | 用語集、出典（資料名・号・判断の基準日）、要約である旨の注記 |

スライドのタイトルは、テーマ名ではなく結論を一文で書きます（例：「REIT：金利上昇が逆風、先進国REITを引き下げ」）。

## 5. シリーズ別のまとめ方

| シリーズ | 頻度 | まとめ方のポイント |
|---|---|---|
| CIO Monthly | 月次 | 表紙の「今月の投資戦略」3点を結論に。CIO VIEW の判断マトリクス、2か月分の判断変更履歴、ファンダメンタルズ・バリュエーションマップ、図表1〜6、1年間の推移、トリガー表 |
| 野村マンスリー投資会議（要約） | 月次 | 株価・金利・為替の予想サマリーを表とグラフに。前号比の上方修正（赤▲）・下方修正（紺▼）を色分け。メインシナリオとリスク要因を対比 |
| グローバル為替・金利展望／国際金融為替（M&W） | 隔週・月次 | 通貨別の予想値・レンジを表とグラフに。金融政策 → 金利差 → 為替の因果をフロー図で |
| 野村週報／週刊チャート展望 | 週次 | 8〜10枚程度。オピニオン、マーケットビュー、今週のカレンダー、トピック、マネーコラム |
| Nomura21 Global | 月次 | 15〜16枚程度。今月の結論と前号比較、銘柄入れ替え（新規・削除）、組み入れ銘柄一覧（日本株・米国株）、テーマ別の図表2枚＋要点、今後の予定。銘柄は「組み入れ銘柄」と書く |
| CIO Quarterly／テーマ銘柄／その他 | 不定期 | 汎用構成。銘柄リストは表にし、「推奨」とは書かず原資料の表現をそのまま使う |

対象外：動画（mp4）、および NotebookLM で作った出力（「GNL」「可視化(NotebookLM)」フォルダの内容）。

## 6. 表現のルール

### 配色

| 意味 | 色 |
|---|---|
| 上昇・引き上げ・追い風・上方修正 | 赤（C00000）▲ |
| 下落・引き下げ・逆風・下方修正 | 紺（1F497D）▼ |
| 中立・維持 | グレー |
| CIO VIEW の5段階 | 紺 → 薄紺 → グレー → 薄赤 → 赤（アンダーウェイト → オーバーウェイト） |

### 数値と出典

- 数値は**原資料に書かれたものだけ**を使います。図から目分量で読み取った値は書きません。
- 図から傾向だけを読み取った場合は「傾向のみ記載」と注記します。
- 原資料の図表の下には「原資料 p.X 図表N」を付けます（ページ番号は原資料の印刷ページ）。
- 各スライドのノート欄に、出典ページと補足を書きます。
- 原資料以外の情報（最新の市場データなど）は加えません。指示があった場合だけ「補足」と明記して分けます。
- 写真・図版は原資料からのみ使い、Web からは持ってきません。

### デザイン

- テンプレートの「タイトルのみ」レイアウトを使います。テンプレート自体からEIZOロゴを削除してあるので、どのレイアウトでもロゴは入りません。
- タイトルは24pt・太字、本文は10.5〜12pt、注記は9pt以上です。
- 強調は淡い色の帯で行い、縁の色帯やタイトル下線は使いません。

旧置き場所の `011_公表情報/_要約スキル資材/` は使っていません（削除して構いません）。

### 変更するときの流れ

1. Claude に変更を依頼する
   → Claude がファイルを直し、取扱説明書・変更履歴も更新したうえで、GitHub に反映します。
2. Claude が示すコマンドを Mac のターミナルで実行し、変更を取り込む（例）
   ```
   cd ~/claude-skills && git pull && git tag -a nomura-summary/v1.0.2 -m "変更内容" && git push --tags
   ```
   ※ 版の目印（タグ）だけは Claude から送れないため、取り込みと同時に Mac で付けます。
3. `SKILL.md` が変わったときは、Claude の設定に保存されたスキルも更新する
   → カードが表示されたら保存します。表示されない場合は、Claude が用意する zip ファイルを「カスタマイズ → Skills」からアップロードし直します（古い nomura-summary を削除してから追加）。

※ Claude から GitHub への反映が権限エラーで断られたときは、Claude が Mac の `~/claude-skills` を直接書き換えます。その場合は `git add -A && git commit -m "…" && git push` で、Mac から反映します（Claude がコマンドを示します）。

### よく使う Git の操作（Mac のターミナル）

| やりたいこと | コマンド |
|---|---|
| 状態を確認する | `cd ~/claude-skills && git status` |
| 変更の履歴を見る | `git log --oneline` |
| 別のパソコンでの変更を取り込む | `git pull` |
| 版の目印（タグ）を付ける | `git tag -a nomura-summary/v1.1.0 -m "説明" && git push --tags` |
| ある版のファイルを見る | `git show nomura-summary/v1.0.0:nomura-summary/SKILL.md` |

## 10. 制限と注意

- **切り出した図表は画像です。** 図の中の数値は編集できません。文字・自作の図解・ネイティブのグラフは編集できます。
- **見出しのない図は自動で拾えません。** 「図表N」という見出しのない図（週報のチャートなど）は、ページを目で確認して切り出します。
- **プレビューと表示が少し違うことがあります。** 作成環境にメイリオがないため、お手元で開くと文字の折り返し位置が少し変わる場合があります。
- **要約は個人的な理解のためのものです。** 投資判断の最終確認は原資料で行ってください。
- **Mac が使える状態である必要があります。** スリープ中や、デスクトップアプリを閉じているときはフォルダを読めません。

## 11. 困ったとき

| 症状 | 対処 |
|---|---|
| 「/nomura-summary」で起動しない | スキルの保存状態を確認する。スキル名の綴りを確認する |
| 「Macに接続できない」と言われる | Mac をスリープから戻し、Claude デスクトップアプリを開いてから再実行する |
| 「フォルダが接続されていない」と言われる | 承認画面で許可する。または「＋」→「フォルダを追加」で `011_公表情報` と `claude-skills` を追加する |
| `git push` で止まる・エラーになる | 表示された内容をそのまま Claude に伝える |
| フォルダが追加できない | フォルダ名に「◆」などの記号があると追加できないことがある。記号を外す |
| 普通の「要約して」で起動してしまう | Claude に伝えれば、スキルの説明文を厳しくする |
| デザイン・構成を変えたい | 「今後は〇〇にして」と伝えれば、スキル本文と資材を更新する |
